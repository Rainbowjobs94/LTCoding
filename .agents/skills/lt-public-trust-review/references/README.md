# LT public-trust review references

The generated, indexed skill pack and executable validators live under
`docs/public-trust/workflows/skillpack/`.

- `coverage.json` records actual versus unavailable application of each named
  skill.
- `skills/*.json` are compact reusable modules with evidence, safety, and
  validation fields.
- `n8n/lt-public-trust-human-review.workflow.json` is an inactive,
  importable, review-only workflow.
- `handoffs/` contains copy-paste Claude and Perplexity briefs.

Do not copy source skill text into public marketing or legal documents. The
pack is an internal review aid and does not grant credentials, legal authority,
financial authority, publication authority, or deployment access.
